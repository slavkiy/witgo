# Базовый component

Этот каталог хранит общий component-артефакт для базового сценария:

- `component.wat` - текстовое представление component;
- `component.wasm` - готовый бинарный артефакт;
- `main.go` - маленький helper, который печатает ожидаемый путь к `.wasm`.

Его используют примеры `server`, `validate` и `inspect`.
